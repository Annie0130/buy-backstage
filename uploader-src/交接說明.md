## 2. 老闆電腦上的上架程式
- 位置：`C:\Users\User\Desktop\feishu-uploader\`（Mac 也可以用，可能放共享資料夾）
- 最外層只有：`★控制台.bat`、`★一鍵上架.bat`、`更新程式.bat`、`★控制台.command`、`更新程式.command`、`照片放這裡\`、`系統\`
- `系統\` 裡：程式、`airtable-token.txt`（Airtable 金鑰，讀＋寫）、`NCC字號.csv`（老闆自己填的字號，優先）、`NCC官方資料.txt`（官方公開資料完全相符的 69 款）、`商品標題.csv`（舊官網標題）、`上架紀錄.csv`、`蝦皮補資料紀錄.csv`、`照片上傳紀錄.csv`、`商品照片\序號\01.jpg…`、`診斷檔\`（錯誤截圖、欄位診斷）
- 瀏覽器登入資料放在每台電腦自己的 `~/.linscam-uploader/chrome-profile-平台`
- 這些資料檔都只在老闆電腦，不在 GitHub。

### 控制台（★控制台.bat → http://localhost:3939）
步驟 1 看拍照順序 → 步驟 2 打開「照片放這裡」→ 步驟 3 一鍵上架 → 步驟 4 蝦皮補資料（等 5～10 分鐘、確認蝦皮出現後再按）。
另有商品狀態表、要重拍照片清單、缺 NCC／BSMI 填寫框（看完拍照順序有缺會自動跳出，填了會記住）、進階功能（批次補 BSMI、批次改蝦皮分類、重新發佈…）。

### 改程式和發佈的方法
1. 改 `buy-backstage/uploader-src/` 裡的檔案（`node --check` 檢查）
2. 執行 `python3 uploader-src/publish-uploader.py "這次更新的中文說明"`
3. `git add -A uploader-src tools && git commit && git push`（main）
4. 老闆按「更新程式.bat」：`update.js` 會從 GitHub raw 和 Netlify 兩邊抓 manifest，用比較新的那邊（Netlify 偶爾會卡住不部署）
- 最外層的啟動檔由 `migrate.js` 的 `LAUNCHERS` 產生，不在 manifest 裡。

### 測試方法
- 一律在暫存資料夾測，用 mock 取代 `global.fetch`（Airtable／官網），用 Playwright 開模擬頁面。
- 這個雲端環境的 Playwright 要加 `executablePath: '/opt/pw-browsers/chromium'`。
- 不要對老闆真實的飛鼠、蝦皮帳號做任何操作。沒在真實網站測過的要跟老闆說。

## 3. 上架規則（老闆定的）
- SPU、SKU 都填序號；定價＝售價；庫存 1；備註「供貨商：進貨管道（空白＝現場客人）」
- 先傳照片到「商品圖片」拖曳框（不是廣告圖），勾「上傳後 AI 自動去背」，**等去背跑完**再填欄位，再按建立
- 建立後自動再按一次「發佈」讓飛鼠推到蝦皮；一鍵上架**不會自動跑蝦皮**（老闆要自己確認後按步驟 4）
- **蝦皮價格：售價 < 15000 → 售價 ×1.18 進位到百、最低購買數量 1；售價 ≥ 15000 → 原價（飛鼠的蝦皮自訂價格要清空）、最低購買數量 3。**
- 蝦皮補資料：保存狀況二手、NCC、BSMI（找不到 BSMI 欄位沒關係，內文有寫）、價格、最低購買數量；存完要確認成功（看成功訊息或重新打開讀回價格／數量），確認成功才把「上架飛鼠」勾拿掉
- 標題：有舊官網標題就沿用（要含型號才算）、沒有就照店裡格式產生；快門 ≤ 1 萬加「快門少」；蝦皮標題 ≤ 60 字含 #序號
- 文案：【型號介紹】（來自收購紀錄的商品介紹，缺的話提醒老闆到後台按「印卡」讓 AI 補）、品相、配件（充電器／充電線合併成充電設備）、保固（原廠在保寫原廠，否則看店保：半年／7 天／無）、BSMI、NCC
- 分類：品牌分類（多選）＋所有口袋機；副廠鏡頭依接環；L 接環鏡頭同時勾 Leica 和 Lumix；CCD／Y2K 勾 CCD、Y2K 分類；CCD 蝦皮分類放「全自動數位相機」
- 照片：每件拍完蓋鏡頭蓋拍 1 張全黑當分隔；相機至少 6 張、鏡頭至少 4 張（多拍不警告）；預覽可在控制台裡多選、拖曳、換組、設主圖
- 拍照順序只列「還沒上架、也還沒有照片」的；已上架的要重拍就加進「要重拍照片」清單

### NCC／BSMI（老闆多次要求違規做法，請維持界線）
- 用：老闆自己填的、官方資料完全相符的、公司貨的品牌代理商 BSMI 碼（Canon R31219、Sony R33021、Fujifilm R33950、Nikon R33697、Olympus／OM R33235、Panasonic R31221、Leica R3B375、Ricoh／Pentax R33B28）
- **不要**：自動套別的型號（近似代替）、別的賣家的號碼、別品牌的碼、照順序編號（D31221/D31222…）。老闆可以自己在填寫框輸入，那是他確認的。
- CCD 相機只寫 BSMI 不寫 NCC。水貨不套代理商碼。

飛鼠電商 自動上架腳本 — 使用說明
=================================

★★★ 最推薦：雙擊「★控制台.bat」★★★
- 瀏覽器會打開「上架控制台」，所有功能都是按鈕，不用再看黑色視窗打字
- 步驟 1 看拍照順序 → 步驟 2 打開收件匣放照片 → 步驟 3 一鍵上架
- 程式問你問題時（例如分組預覽對不對），右邊會出現黃色框，直接按「✅ 正確」
- 下面「商品狀態」會列出每一件：還沒上架／草稿／蝦皮待補／🚨要馬上處理／完成
- 補照片清單直接在網頁上加序號
- 跑控制台時，旁邊那個黑色視窗不要關（關掉控制台就停了）

★★ 不用控制台的話：用「★一鍵上架.bat」這一顆 ★★
1. 收購後台：填售價、勾選商品、按「🛒 標記上架飛鼠」
   （已經上架、要補照片的：把序號一行一個打進「補照片清單.txt」存檔）
2. 雙擊「★一鍵上架.bat」→ 收件匣沒照片時，它只會跳出「拍照順序」，什麼都不會上架
3. 照順序拍，每件拍完蓋鏡頭蓋拍 1 張全黑
4. 照片全部放進 商品照片\收件匣
5. 再雙擊同一顆「★一鍵上架.bat」→ 分組預覽（輸入 y）→ 新商品建立、補照片的傳上去 → 蝦皮補資料
   補照片清單用完會自動清空
- 只想補照片（草稿或已上架）：雙擊「補照片.bat」，輸入序號按 Enter
- 檢查蝦皮價格有沒有賣錯：雙擊「蝦皮價格檢查.bat」（不對會自動改，改不了會出現 🚨）
- 想看還有什麼沒做完：雙擊「待辦清單.bat」
- 其他按鈕都收在「其他功能」資料夾，平常不用碰
- 程式有更新時：雙擊「更新程式.bat」就好（不用再解壓縮）

【第一次安裝】（只要做一次）
1. 安裝 Node.js（https://nodejs.org 下載 LTS 版，一路下一步）
2. 把整個 feishu-uploader 資料夾放到電腦上（例如桌面）
3. 在資料夾裡開啟「命令提示字元 / 終端機」，輸入：
     npm install

4. 建立 Airtable 唯讀金鑰（讓腳本讀收購紀錄）：
   a. 打開 https://airtable.com/create/tokens ，按「Create token」
   b. Name：隨便取，例如「飛鼠上架用」
   c. Scopes：加 data.records:read 和 data.records:write（write 只用來回寫「飛鼠狀態」）
   d. Access：只加「林相攝影收購紀錄」這個 base
   e. 按 Create token，複製那串 pat 開頭的金鑰
   f. 在 feishu-uploader 資料夾裡新增文字檔 airtable-token.txt，把金鑰貼進去存檔
   ※ 金鑰等同鑰匙，不要傳給別人、不要貼到聊天室

【每次上架】
1. 在收購後台：
   a. 把要上架的商品填好「售價」
   b. 打開右上的「☑️ 勾選匯入模式」，勾選要上架的商品，按「🛒 標記上架飛鼠」
      （送修、不上架的不要標記；標錯了勾起來按「取消上架標記」）
2. 先看看會上架哪些：
     node upload.js airtable --list
3. 沒問題就正式開始：
     node upload.js airtable
   （加 --draft 會每筆自動存草稿；加 --limit 1 只跑 1 筆）
4. 會跳出 Chrome，第一次請自己登入飛鼠後台（之後會記住）
5. 回終端機按 Enter，腳本開始逐筆填表

【會自動帶入的資料】
  收購紀錄（Airtable）   → 飛鼠後台
  器材一                 → 商品名稱
  序號                   → SPU 編號、SKU 貨號
  售價                   → 定價、售價
  收購總金額             → 成本
  （依名稱自動判斷）     → 品牌、分類
  後台「📝 文案」同格式   → 商品描述
  商品介紹（AI 規格介紹） → 商品特色 1
  貨品來源、快門數、盒單  → 商品屬性
  現場客人               → 備註 (管理人員使用)，買家看不到

  ※ 不會讀取客戶姓名、身分證、電話等個資

【自動判斷品牌／分類】
- 例如 Canon RF 24-70mm → Canon / Canon 鏡頭；Fujifilm XS20 → Fujifilm / Fujifilm 相機
- 副廠鏡頭依接環放進原廠分類：Tamron … For fuji → 品牌 Tamron / 分類 Fujifilm 鏡頭
- Sigma 鏡頭也依接環放（for Sony → Sony 鏡頭）；沒寫接環才放 Sigma 鏡頭；Sigma fp 等相機放 Sigma 相機
- 沒寫接環、M43、L 接環和配件判斷不出分類，填表時請在瀏覽器手動選
- 終端機會列出每筆判斷結果，填表時請順便確認

【模式】（打開 upload.js 最上面的設定區修改）
  mode: 'review'  只填表，你檢查後自己按儲存（預設，建議先用這個）
  mode: 'draft'   自動按「儲存草稿」
  mode: 'create'  自動按「建立」直接上架
  limit: 1        只跑第一筆，測試用
  airtable.sinceDate: '2026-11-01'  只抓這天之後收購的商品

【配件整理】
- 文案的配件說明裡，充電器、充電線會合併成「充電設備」（有原廠就寫「原廠充電設備」）
- 只改上架文案，不會改收購紀錄裡的原始資料

【蝦皮最低購買數量改 3（售價 2 萬以上）】
- 飛鼠按「建立」後約 2 分鐘會同步到蝦皮，之後執行：
     node upload.js shopee
  （舊指令 node shopee-minqty.js 也可以）
- 第一次會要你在跳出的 Chrome 登入蝦皮賣家中心（之後會記住）
- 它會自動找：收購後台有標記、售價 ≥ 2 萬、飛鼠已上架成功的商品
- 用序號（＝蝦皮主商品貨號）搜尋 → 編輯 → 銷售資訊 → 最低購買數量改 3
- 預設每筆停下來讓你自己按「更新」；確認沒問題後可加 --auto 自動儲存：
     node shopee-minqty.js --auto
- 只改特定商品：node shopee-minqty.js 70039
- 不能跟 upload.js 同時跑（共用同一個 Chrome 登入資料）

【商品圖片】
- 目前「不上傳」佔位圖（upload.js 設定區 placeholderImage: ''）
- 想打開：把 placeholderImage 改成 path.join(__dirname, '拍攝中.jpg')
- 想換圖：用同樣檔名「拍攝中.jpg」覆蓋即可；不想上傳：把這個檔案刪掉或改名

【★ 一鍵上架：先拍照，再一次上架（最推薦）】
1. 收購後台：填售價、勾選商品、按「🛒 標記上架飛鼠」
2. 雙擊「其他功能\0_拍照順序.bat」→ 看拍照順序（也存成 拍照順序.txt）
3. 照順序拍：相機 6 張、鏡頭 4～6 張；每拍完一件，一定要蓋上鏡頭蓋拍 1 張「全黑」當分隔
   （張數不對、或沒拍黑畫面，預覽會警告）
4. SD 卡裡的照片全部放進：feishu-uploader\商品照片\收件匣（RAW 檔會自動略過）
5. 雙擊「★一鍵上架.bat」
   ① 照片依黑畫面分組 → 自動打開「照片分組預覽.html」→ 確認對了輸入 y
      （組數跟商品數不一樣時會警告，要輸入 yes 才會繼續）
   ② 有照片的商品直接按「建立」上架；沒照片或有欄位沒填好的先存草稿、不上架
   ③ 等 2 分半讓飛鼠同步到蝦皮
   ④ 蝦皮補資料（保存狀況二手、NCC、2 萬以上最低購買數量 3）
- 照片會縮小到最長邊 2000px，放在 商品照片\序號\01.jpg、02.jpg…（01 是主圖）
- 分錯的話：可以直接到 商品照片\序號 資料夾裡調整照片，再上架
- 原始照片會移到 商品照片\已處理\日期時間，不會刪掉
- 只想分組照片：雙擊「其他功能\0_照片分組.bat」

【之前存成草稿的商品，補照片並發佈】
- 雙擊「其他功能\0_拍照順序.bat」：草稿會標【飛鼠已是草稿，等補照片】，照順序拍
- 照片放進 商品照片\收件匣，雙擊「★一鍵上架.bat」就會：分組 → 草稿補照片並按「發佈」→ 新商品建立 → 蝦皮補資料
- 只想處理草稿：照片分好組後（其他功能\0_照片分組.bat），雙擊「其他功能\4_草稿補照片並發佈.bat」

【單獨補照片（草稿或已上架都可以）】
- 最簡單：序號打進「補照片清單.txt」，用「★一鍵上架.bat」照上面步驟跑
- 用「0_拍照順序」「0_照片分組」把照片整理到 商品照片\序號
- 雙擊「補照片.bat」：搜尋序號 → 打開商品編輯 → 上傳照片 → 按「發佈／更新／儲存」（不會按儲存草稿）
- 同一批照片不會重複上傳（記在 照片上傳紀錄.csv）；重新拍、重新分組後才會再傳
- 補上的照片會加在原本的照片後面，舊照片要刪請到飛鼠手動刪
- 只補特定商品：node upload.js addphotos 70039

【最簡單：雙擊就跑】
  其他功能\1_飛鼠上架（存草稿）.bat   雙擊 → 收購後台有標記的商品全部自動存成飛鼠草稿
  （之後到飛鼠補實拍照、按「建立」，這步不用碰終端機）
  其他功能\2_蝦皮補資料.bat           雙擊 → 已建立的商品補蝦皮資料（一天跑一次就好）
  待辦清單.bat             雙擊 → 列出還沒上架／還是草稿／蝦皮還沒補的商品（也存成 待辦清單.txt）

【不用守在電腦旁的跑法】
  node upload.js airtable --draft     飛鼠：每筆自動存草稿，不會停
  node upload.js shopee --auto        蝦皮：保存狀況二手、NCC、2 萬以上最低購買數量 3，自動儲存
- 已經登入就會直接開始；有問題的那筆會記在紀錄檔、存錯誤截圖，然後繼續下一筆
- 跑完瀏覽器會自動關掉，回來看紀錄檔（上架紀錄.csv、蝦皮補資料紀錄.csv）就好

【NCC / BSMI 字號】
- 第一次執行後，資料夾裡會出現 NCC字號.csv，用 Excel 或記事本打開
- 一行一個型號：型號,NCC字號,BSMI字號　例如：A6600,CCAxxxxxxxxxx,Rxxxxx
- 型號寫完整一點（寫 A7M4，不要只寫 A7，不然 A7C 也會對到）
- 之後同型號的文案會自動帶入；表裡沒有的會寫「（請自行填入）」並提醒你

【沒有無線功能的相機（例如老 CCD）】
- 在 NCC字號.csv 把那個型號的 NCC 欄填「無」，備註清空
- 文案會寫「本商品無 Wi-Fi／藍牙等無線傳輸功能，非電信管制射頻器材，無須 NCC 審驗」
- 蝦皮的 NCC 欄位就不會填，也不會再提醒你
- ⚠️ 只填你確認過真的沒有 Wi-Fi／藍牙的型號

【收購後台顯示上架狀態】
- 上架後，收購後台的「🛒 待上架飛鼠」會自動變成：📝 飛鼠草稿 → 🛍️ 飛鼠已上架 → ✅ 已上架＋蝦皮
- 要讓腳本能寫回去，金鑰要多一個「寫入」權限（只要做一次）：
  a. 打開 https://airtable.com/create/tokens ，找到原本的金鑰（例如「飛鼠上架用」）按進去
  b. Scopes 加上 data.records:write（原本的 data.records:read 保留）
  c. 按 Save changes（金鑰本身不會變，airtable-token.txt 不用改）
- 腳本只會寫「飛鼠狀態」這一欄，不會改其他資料
- 沒開寫入權限也可以上架，只是收購後台的狀態不會變

【其他】
- 上架紀錄.csv 會記錄結果；成功的商品重跑時不會重複上架
- 商品圖片要手動上傳
- 舊方式仍可用：node upload.js 商品.xlsx（從 Google 試算表下載的 Excel）
